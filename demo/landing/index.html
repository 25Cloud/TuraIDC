三个界面，随便点

这里是 TuraIDC 的在线演示：用户端、控制台、管理端都是真实构建的前端产物，跑在浏览器里， 后面没有任何后端。数据是编好的示例数据，所以你可以一路点到底，不会动到任何真实资源。

  • 用户端

    /

    客户看到的站点：逛商品、选配置、下单、看公告与帮助。

    • 首页与商品目录
    • 商品详情与配置选购
    • 下单结算流程
    进入用户端 →

  • 用户控制台

    /console/

    客户买到机器之后每天用的地方：开关机、看用量、续费、提工单。

    • 概览、我的服务、实例详情
    • 快照 / ISO / 安全组面板
    • 账单、充值、工单、账户设置
    进入控制台 →

  • 管理端

    /admin/

    站长视角：经营看板、商品与订单、用户与财务、系统设置与插件。

    • 经营看板与订单台账
    • 商品、用户、财务、工单
    • 插件与系统设置
    进入管理端 →

几点说明

  • 数据全部是示例数据（客户、实例、账单、工单都在 demo/fixtures 里写死），刷新页面即回到初始状态。
  • 删除实例、退款、重置密码这类动作不会执行，会返回「演示环境不执行该操作」——这是刻意的，避免你以为真删了什么。
  • 接口请求不出浏览器，所以没有后端、没有延迟、也不会跳去真实站点。
  • 想自己跑一套：看部署文档，或 拉源码。
