# 雨云 RCS 插件

插件目录为 `backend/plugins/servers/rainyun_rcs/`，后台能力域为 `upstream`，标识为 `rainyun_rcs`。本插件对接雨云 RCS，参考魔方财务 rainyunrcs 3.0.0 的业务功能重新实现。

## 1. 安装前提

本版本需要配套的图拉核心能力补丁和用户控制台构建，不能只把插件 ZIP 上传到未升级的旧版图拉。

交付包为 `TuraIDC-rainyun-rcs-1.0.0.zip`，内含 `rainyun_rcs-1.0.0.zip`、`TuraIDC-rainyun-rcs-integration.patch`、安装说明、许可文件及校验清单。补丁基线是图拉提交 `ec1afcb4b2920ae6e71fd5b92d5197341b10de19`；不同版本必须先检查补丁，不要直接覆盖整个应用。

配套能力包括：插件本地控制台动作、插件附加订单履约、官方浏览器控制台直连、插件重装请求时限。平台只有在当前实例绑定的插件明确实现对应接口时才启用相关分支；普通上游继续使用原有流程。

1. 备份站点代码，确认当前版本与补丁基线相符。在仓库根目录先运行 `git apply --check TuraIDC-rainyun-rcs-integration.patch`，检查通过后再应用。补丁包含完整插件代码；不要重复覆盖已有本地改动。
2. 按站点原有发布流程部署后端，并在 `frontend-user-v4-console` 执行 `pnpm run build` 后部署构建产物。重新加载长驻队列工作进程，清理旧应用缓存。
3. 在管理端插件管理中扫描、安装并启用“雨云 RCS”。无需新增数据库表或系统路由。
4. 新建或编辑供应商，选择“雨云 RCS”，填写 API 地址与 API Key，再查询余额验证连通性。密钥只配置到供应商凭据，不放进商品、用户端面板或文档。
5. 同步上游套餐、配置项和库存，设置本站销售价格，再关联测试实例检查控制台。

若图拉已经包含这些配套能力，可单独解压插件 ZIP，将 `rainyun_rcs` 目录放入 `backend/plugins/servers/` 后扫描安装。

## 2. 供应商与销售价格

雨云 API 地址为 `https://api.v2.rainyun.com`，请求头由插件设置 `x-api-key`。雨云官方接口文档位于 <https://api.rainyun.com/>。

| 配置                       | 含义                                                                         |
| -------------------------- | ---------------------------------------------------------------------------- |
| API Key                    | 雨云账户的 API 密钥，缺省时拒绝请求                                          |
| 固态、机械、系统机械盘单价 | 对应云盘每 GB 每月的本站销售价格                                             |
| 云盘备份单价               | 开启备份后，每 GB 每月的附加销售价格                                         |
| 附加流量单价               | 每 GB 销售价格                                                               |
| GPU 时长单价               | 每小时销售价格                                                               |
| 套餐月销售价格 JSON        | 套餐 ID 到月销售价格的映射，例如 `{"1001":"30.00","1002":"60.00"}`           |
| IP 月销售价格 JSON         | 线路标识到单个 IPv4 月销售价格的映射，空标识表示默认线路，例如 `{"":"8.00"}` |

金额最多两位小数。销售价格缺失或无效时，对应购买会被拒绝，不能免费调用上游付费接口。套餐升级必须同时配置当前与目标套餐的销售价格，并且目标必须出现在雨云返回的可升级列表中。

导入模板默认不附加付费 IP、额外系统盘容量，不启用试用。若要开放开通时的附加配置或试用，由站长在商品配置中显式设置选项、默认值与价格；模板的基础套餐价格不能当成任意附加配置的总价。开通与续费支持月付、季付、半年付、年付。

## 3. 控制台功能

| 功能                   | 行为                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 开关机、重启、密码重置 | 经图拉鉴权后调用当前绑定实例的雨云接口                                             |
| 重装                   | 校验镜像后自动关机，等待确认停止，再提交重装；无效镜像不会关机，停机超时不提交重装 |
| VNC                    | 获取雨云官方页面链接，在新窗口访问；不改写签名参数，不走图拉 WebSocket 中转        |
| 终端                   | 获取 xtermjs 官方入口后，点击“打开雨云终端”直接访问雨云                            |
| 监控                   | CPU、内存、磁盘与网络时间序列                                                      |
| 备份与快照             | 创建、删除、还原、自动计划；备份支持取消任务                                       |
| NAT                    | NAT 实例显示端口转发列表、新增与删除；资源 ID 必须属于当前实例                     |
| 云盘                   | 新建、扩容、调整备份、删除数据盘；禁止缩容与删除系统盘                             |
| 流量与 GPU             | 流量包、每日流量限额、限速、GPU 开关与时长购买                                     |
| 套餐与 IP              | 套餐升级、附加 IPv4 购买                                                           |

VNC 与终端页面、WebSocket 均由浏览器直连雨云。图拉后端只请求入口链接及普通管理 API。若雨云未返回 `VNCProxyURL`，插件明确提示不可用；不提供旧式 `RequestURL/PVEAuth` 转发方案。链接失效时重新获取。

雨云重装请求允许前端等待 90 秒，插件内部前置操作总预算为 55 秒，并受平台实例操作锁保护。部署时 PHP 请求时限、反向代理读取时限应允许该请求完成。重装提交成功表示雨云已接受任务，不表示安装已完成；通过状态刷新确认恢复运行。

## 4. 附加资源账单与重试

1. 用户先获取报价并确认。报价有效期十分钟，绑定服务、供应商、插件、上游实例和资源配置。
2. 创建图拉升级账单，等待付款；同一确认报价重复提交时复用原账单，付款完成后也不另建订单。已有其他待支付升级账单时，先支付或取消该账单。
3. 付款后重新检查实例绑定与资源状态，再执行一次雨云操作。
4. 云盘、套餐和 IP 的月续费差额同步更新服务金额及相应续费周期配置。云盘退款在上游成功后生成余额流水与退款单据，不记为手工充值。

按原插件口径，以 31 天为一个月折算剩余服务期；附加流量和 GPU 时长按购买数量计费。云盘删除及关闭备份的负差额按配置的销售单价返还。迁入实例和调整供应商销售价前，站长应核对该实例已有云盘费用是否计入图拉续费金额，避免历史定价与现配置不一致。

订单快照状态：`ready` 待执行，`submitted` 已发起，`applied` 上游已接受，`uncertain` 结果不明，`rejected` 上游拒绝。`submitted/uncertain/rejected` 不自动重发收费请求。换绑实例、变更上游资源或续期后，旧报价不能继续执行。需核对上游真实结果及账单，再按平台现有人工账务流程处理；不要清空执行状态后盲目重试。

## 5. 验证边界

2026-10-21 已在授权空白实例上验证详情、套餐、镜像、监控、余额与两种官方控制台入口，并通过新插件执行“运行中 → 自动关机 → Debian 11 重装”。浏览器验证了连接直达雨云 WebSocket。

开通新机、实际续费、套餐升级、IP/云盘/流量/GPU 购买未执行真实扣款。备份还原及快照等资源操作以契约回归为主，生产启用前应在对应测试资源验证。原插件没有真实欠费封禁能力，本插件也不把普通关机伪装成封禁；不要把暂停状态下的自动处置视为已验证的上游能力。

上线前仍需站长提供计划销售的套餐与价格，并以明确的消费预算验证“支付 → 上游扣款 → 资源变化 → 续费价格”流程。
