# 初始配置

部署完成到正式对外销售之间的配置工作。按本文顺序做完，再上架商品——支付渠道或上游供应商没配好就放量，会出现用户付了钱却开不出机器的情况。

## 1. 配置顺序

| 顺序 | 配置项                             | 说明                                                   |
| ---- | ---------------------------------- | ------------------------------------------------------ |
| 1    | [站点与品牌设置](site-settings.md) | 站点名称、浏览器标题、Logo、主题色等三端可见信息       |
| 2    | [邮件与短信](mail-and-sms.md)      | 通知通道；不配则注册验证码、开通通知、工单提醒都发不出 |
| 3    | [支付渠道接入](payment.md)         | 用户付钱进来的通道，含回调地址与密钥纪律               |
| 4    | [上游供应商对接](upstream.md)      | 机器从哪里开出来：凭据、库存与定价同步、连通性自检     |

## 2. 上线检查清单

- 站点名称与浏览器标题已改成本站品牌，前后台与官网均已生效。
- 邮件能收到测试信，短信能收到测试验证码。
- 支付渠道的异步回调地址指向生产域名，且已在渠道侧登记。
- 上游供应商连通性自检通过，至少一个商品能查到真实库存与价格。
- [部署与调度](../deploy/scheduling.md)里的计划任务、队列与心跳已在运行。

## 3. 相关约束

- 密钥、Token、私钥只写在服务器环境变量或后台加密配置里，不写进文档、截图或工单。
- 签名与令牌类密钥读到空值时必须拒绝服务，不允许降级成「空密钥照常计算」。
- 修改品牌与站点信息后，静态资源可能被缓存，需要按[前端站点 Nginx 规则](../maintain/nginx-rules.md)确认缓存策略。
