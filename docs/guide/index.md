# 使用者文档

面向部署并运营 TuraIDC 的站长与运营人员。这里只讲怎么把站跑起来、怎么配置业务、怎么运营、出问题怎么查；要看系统结构、接口契约或改代码，请进[开发者文档](../develop/index.md)。

## 1. 按阶段进入

| 阶段     | 你要完成的事                                       | 入口                            |
| -------- | -------------------------------------------------- | ------------------------------- |
| 部署安装 | 选部署方式、准备环境、跑起后端与三端前端           | [部署安装](deploy/index.md)     |
| 初始配置 | 站点与品牌、邮件与短信、支付渠道、上游供应商       | [初始配置](configure/index.md)  |
| 日常运营 | 商品上架、订单开通、资金对账、客服工单、通知       | [日常运营](operate/index.md)    |
| 维护升级 | 版本升级、备份恢复、日志归档、前端站点 Nginx 规则  | [维护与升级](maintain/index.md) |
| 数据迁移 | 从智简魔方财务系统或旧 IDC 系统迁移业务数据        | [数据迁移](migrate/index.md)    |
| 许可合规 | 确认 AGPL 免费路径的强制义务，判断是否需要商业授权 | [开源与商业许可](licensing.md)  |
| 故障排查 | 站点打不开、队列不跑、邮件发不出等问题的定位与处理 | [故障排查](troubleshooting.md)  |

## 2. 上线最短路径

1. 按[部署安装](deploy/index.md)选择一种方式完成部署，再照[部署与调度](deploy/scheduling.md)配好计划任务、队列与心跳——漏掉这一步，自动开通、自动续费与通知都不会执行。
2. 进[初始配置](configure/index.md)配好站点名称与品牌、邮件与短信、支付渠道、上游供应商，然后才上架商品。
3. 用一笔真实的小额订单走通「下单 → 支付 → 自动开通 → 通知」，确认闭环后再放量。
4. 把[备份与恢复](maintain/backup.md)设成定时任务，再开始对外销售。

## 3. 环境自检

部署完成后可随时自检 PHP 版本、必需扩展与禁用函数；升级 PHP 或改动 `php.ini` 后也应复核：

```bash
cd backend
php artisan app:doctor          # 必选项：版本、必需扩展、禁用函数
php artisan app:doctor --all    # 附带列出建议安装但不阻断的扩展
```
