## 状态约定

- 页面归类：真实页面 / 重定向 / 隐藏详情页 / 聚合 tab / 兼容入口。
- 验收状态：未开始 / 进行中 / 通过 / 不适用。
- API 方法、权限码和测试用例必须在迁移对应页面时补充到方法级。
