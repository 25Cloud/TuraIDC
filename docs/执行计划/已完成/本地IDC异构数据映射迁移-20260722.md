# 本地 IDC 异构数据映射迁移

## 背景

将指定 MySQL dump 的基础表和数据恢复到独立 utf8mb4 中转库，再按字段映射写入本地开发库 idc 的既有最终结构。目标 idc 不允许执行任何 DDL。

## 范围与验收

- [ ] 先完成可恢复的全量备份和迁移前结构快照。
- [ ] 中转库仅恢复基础表和数据；跳过 dump 中的视图、触发器、事件和例程。
- [ ] 生成字段差异矩阵、可复用 JSON 映射和 INSERT SELECT 脚本。
- [ ] 目标端只执行允许的 DML 与会话级外键设置。
- [ ] 完成结构、行数、核心字段哈希、外键和 Laravel 冒烟验收。

## 实施步骤

1. 备份 idc，记录 SHOW CREATE TABLE 指纹。
2. 创建唯一的 idc_temp_restore 中转库并恢复经过对象过滤的 dump。
3. 分析元数据，生成并审阅映射配置。
4. 在外键检查关闭期间按映射清空和导入目标数据；失败时以数据备份回滚。
5. 运行结构与数据验收，记录输出和遗留风险。

## 风险与回滚

- 风险：异构字段、唯一键、旧日期值、分类层级和外键引用可造成导入不一致。
- 结构保护：idc 禁止 CREATE、ALTER、DROP、TRUNCATE；自增只自然推进并校验。
- 回滚：仅用阶段一的数据备份和目标 DML 恢复；任何映射未定义错误连续三表即停止并触发回滚。
