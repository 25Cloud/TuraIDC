# 初始配置

部署完成到正式對外銷售之間的配置工作。按本文順序做完，再上架商品——支付渠道或上游供應商沒配好就放量，會出現用戶付了錢卻開不出機器的情況。

## 1. 配置順序

| 順序 | 配置項                             | 説明                                                   |
| ---- | ---------------------------------- | ------------------------------------------------------ |
| 1    | [站點與品牌設置](site-settings.md) | 站點名稱、瀏覽器標題、Logo、主題色等三端可見信息       |
| 2    | [郵件與短信](mail-and-sms.md)      | 通知通道；不配則註冊驗證碼、開通通知、工單提醒都發不出 |
| 3    | [支付渠道接入](payment.md)         | 用戶付錢進來的通道，含回調地址與密鑰紀律               |
| 4    | [上游供應商對接](upstream.md)      | 機器從哪裡開出來：憑據、庫存與定價同步、連通性自檢     |

## 2. 上線檢查清單

- 站點名稱與瀏覽器標題已改成本站品牌，前後台與官網均已生效。
- 郵件能收到測試信，短信能收到測試驗證碼。
- 支付渠道的異步回調地址指向生產域名，且已在渠道側登記。
- 上游供應商連通性自檢通過，至少一個商品能查到真實庫存與價格。
- [部署與調度](../deploy/scheduling.md)裡的計劃任務、隊列與心跳已在運行。

## 3. 相關約束

- 密鑰、Token、私鑰只寫在伺服器環境變量或後台加密配置裡，不寫進文檔、截圖或工單。
- 簽名與令牌類密鑰讀到空值時必須拒絕服務，不允許降級成「空密鑰照常計算」。
- 修改品牌與站點信息後，靜態資源可能被快取，需要按[前端站點 Nginx 規則](../maintain/nginx-rules.md)確認快取策略。
