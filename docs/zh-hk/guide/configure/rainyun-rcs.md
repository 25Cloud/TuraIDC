# 雨雲 RCS 插件

插件目錄為 `backend/plugins/servers/rainyun_rcs/`，後台能力域為 `upstream`，標識為 `rainyun_rcs`。本插件對接雨雲 RCS，參考魔方財務 rainyunrcs 3.0.0 的業務功能重新實現。

## 1. 安裝前提

本版本需要配套的圖拉核心能力補丁和用戶控制台構建，不能只把插件 ZIP 上傳到未升級的舊版圖拉。

交付包為 `TuraIDC-rainyun-rcs-1.0.0.zip`，內含 `rainyun_rcs-1.0.0.zip`、`TuraIDC-rainyun-rcs-integration.patch`、安裝説明、許可文件及校驗清單。補丁基線是圖拉提交 `ec1afcb4b2920ae6e71fd5b92d5197341b10de19`；不同版本必須先檢查補丁，不要直接覆蓋整個應用。

首次交付包不包含隨後實測補齊的試用週期適配與缺少 IP 的錯誤提示。使用該包時還需應用 `TuraIDC-rainyun-rcs-trial-fix.patch`；此增量補丁基於已接入 1.0.0 的提交 `1661398`，同樣先執行 `git apply --check`。工作區已包含這些修改時不要重複應用。

配套能力包括：插件本地控制台動作、插件附加訂單履約、官方瀏覽器控制台直連、插件重裝請求時限。平台只有在當前實例綁定的插件明確實現對應接口時才啟用相關分支；普通上游繼續使用原有流程。

1. 備份站點代碼，確認當前版本與補丁基線相符。在倉庫根目錄先運行 `git apply --check TuraIDC-rainyun-rcs-integration.patch`，檢查通過後再應用。補丁包含完整插件代碼；不要重複覆蓋已有本地改動。
2. 按站點原有發佈流程部署後端，並在 `frontend-user-v4-console` 執行 `pnpm run build` 後部署構建產物。重新加載長駐隊列工作進程，清理舊應用快取。
3. 在管理端插件管理中掃描、安裝並啟用“RCS”（標識 `rainyun_rcs`）。無需新增數據庫表或系統路由。
4. 新建或編輯供應商，選擇“RCS”，填寫 API 地址與 API 密鑰，再查詢餘額驗證連通性。密鑰只配置到供應商憑據，不放進商品、用戶端面板或文檔。
5. 同步上游套餐、配置項和庫存，設置本站銷售價格，再關聯測試實例檢查控制台。

若圖拉已經包含這些配套能力，可單獨解壓插件 ZIP，將 `rainyun_rcs` 目錄放入 `backend/plugins/servers/` 後掃描安裝。

## 2. 供應商與銷售價格

雨雲 API 地址為 `https://api.v2.rainyun.com`，請求頭由插件設置 `x-api-key`。雨雲官方接口文檔位於 <https://api.rainyun.com/>。

| 配置                       | 含義                                                                         |
| -------------------------- | ---------------------------------------------------------------------------- |
| API Key                    | 雨雲賬戶的 API 密鑰，缺省時拒絕請求                                          |
| 固態、機械、系統機械盤單價 | 對應雲盤每 GB 每月的本站銷售價格                                             |
| 雲盤備份單價               | 開啟備份後，每 GB 每月的附加銷售價格                                         |
| 附加流量單價               | 每 GB 銷售價格                                                               |
| GPU 時長單價               | 每小時銷售價格                                                               |
| 套餐月銷售價格 JSON        | 套餐 ID 到月銷售價格的映射，例如 `{"1001":"30.00","1002":"60.00"}`           |
| IP 月銷售價格 JSON         | 線路標識到單個 IPv4 月銷售價格的映射，空標識表示默認線路，例如 `{"":"8.00"}` |

金額最多兩位小數。銷售價格缺失或無效時，對應購買會被拒絕，不能免費調用上游付費接口。套餐升級必須同時配置當前與目標套餐的銷售價格，並且目標必須出現在雨雲返回的可升級列表中。

導入模板默認不附加付費 IP、額外系統盤容量，不啟用試用。若要開放開通時的附加配置或試用，由站長在商品配置中顯式設置選項、默認值與價格；模板的基礎套餐價格不能當成任意附加配置的總價。開通與續費支持月付、季付、半年付、年付。

試用開通支持訂單週期 `ontrial`（經平台統一規範化也識別 `trial`、`on_trial`），或顯式配置 `try=true`；插件向雨雲發送試用開關，`duration` 仍使用接口允許的月數。此適配不改變圖拉商城的週期白名單，也不把試用加入續費週期。

部分區域必須附帶獨立 IP。套餐 1344 實測在數量為 0 時返回 `70033`，配置為 `with_eip_num=1`、`with_eip_flags=native` 後試用創建成功。該套餐還提供 `home_ip` 線路；IP 數量、線路與對應售價須在商品中顯式配置，不能沿用“不附加 IP”的默認選項。IP 線路標識與 IPv4/IPv6 地址類型是不同參數。

## 3. 控制台功能

| 功能                   | 行為                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 開關機、重啟、密碼重置 | 經圖拉鑑權後調用當前綁定實例的雨雲接口                                             |
| 重裝                   | 校驗鏡像後自動關機，等待確認停止，再提交重裝；無效鏡像不會關機，停機超時不提交重裝 |
| VNC                    | 獲取雨雲官方頁面鏈接，在新窗口訪問；不改寫簽名參數，不走圖拉 WebSocket 中轉        |
| 終端                   | 獲取 xtermjs 官方入口後，點擊“打開終端”直接訪問上游                                |
| 監控                   | CPU、記憶體、磁盤與網絡時間序列                                                      |
| 備份與快照             | 創建、刪除、還原、自動計劃；備份支持取消任務                                       |
| NAT                    | NAT 實例顯示端口轉發列表、新增與刪除；資源 ID 必須屬於當前實例                     |
| 雲盤                   | 新建、擴容、調整備份、刪除數據盤；禁止縮容與刪除系統盤                             |
| 流量與 GPU             | 流量包、每日流量限額、限速、GPU 開關與時長購買                                     |
| 套餐與 IP              | 套餐升級、附加 IPv4 購買                                                           |

VNC 與終端頁面、WebSocket 均由瀏覽器直連雨雲。圖拉後端只請求入口鏈接及普通管理 API。若雨雲未返回 `VNCProxyURL`，插件明確提示不可用；不提供舊式 `RequestURL/PVEAuth` 轉發方案。鏈接失效時重新獲取。

插件展示名、操作提示、套餐配置、終端按鈕及新生成的附加資源賬單與退款描述使用中性文案，不包含“雨雲”。插件標識、接口地址與綁定校驗仍沿用原值；已有商品配置和歷史賬務記錄不會被自動改寫。

雨雲重裝請求允許前端等待 90 秒，插件內部前置操作總預算為 55 秒，並受平台實例操作鎖保護。部署時 PHP 請求時限、反向代理讀取時限應允許該請求完成。重裝提交成功表示雨雲已接受任務，不表示安裝已完成；通過狀態刷新確認恢復運行。

## 4. 附加資源賬單與重試

1. 用戶先獲取報價並確認。報價有效期十分鐘，綁定服務、供應商、插件、上游實例和資源配置。
2. 創建圖拉昇級賬單，等待付款；同一確認報價重複提交時複用原賬單，付款完成後也不另建訂單。已有其他待支付升級賬單時，先支付或取消該賬單。
3. 付款後重新檢查實例綁定與資源狀態，再執行一次雨雲操作。
4. 雲盤、套餐和 IP 的月續費差額同步更新服務金額及相應續費週期配置。雲盤退款在上游成功後生成餘額流水與退款單據，不記為手工充值。

按原插件口徑，以 31 天為一個月折算剩餘服務期；附加流量和 GPU 時長按購買數量計費。雲盤刪除及關閉備份的負差額按配置的銷售單價返還。遷入實例和調整供應商銷售價前，站長應核對該實例已有云盤費用是否計入圖拉續費金額，避免歷史定價與現配置不一致。

訂單快照狀態：`ready` 待執行，`submitted` 已發起，`applied` 上游已接受，`uncertain` 結果不明，`rejected` 上游拒絕。`submitted/uncertain/rejected` 不自動重發收費請求。換綁實例、變更上游資源或續期後，舊報價不能繼續執行。需核對上游真實結果及賬單，再按平台現有人工賬務流程處理；不要清空執行狀態後盲目重試。

## 5. 驗證邊界

2026-10-21 已在授權空白實例上驗證詳情、套餐、鏡像、監控、餘額與兩種官方控制台入口，並通過新插件執行“運行中 → 自動關機 → Debian 11 重裝”。瀏覽器驗證了連接直達雨雲 WebSocket。

同日通過插件的真實開通入口驗證了套餐 1344、鏡像 535（Debian 12）、試用週期和一個 `native` IPv4：實例完成創建並進入運行中，試用標記、鏡像和 IP 線路正確，賬戶餘額減少 1 元；SSH 端口可達並返回 Debian 服務標識。再次調用開通入口只複用已保存的實例 ID，沒有向上遊發送寫請求。本次使用隔離的本地訂單夾具與真實上游接口，不包含圖拉前台下單、支付網關或真實業務數據庫聯調。

正式付費新購、實際續費、套餐升級、售後附加 IP/雲盤/流量/GPU 購買未執行真實扣款；`home_ip` 只核對報價和參數，未創建第二台機器驗證。用戶要求本輪不測磁盤升降級。備份還原及快照等資源操作以契約迴歸為主，生產啟用前應在對應測試資源驗證。原插件沒有真實欠費封禁能力，本插件也不把普通關機偽裝成封禁；不要把暫停狀態下的自動處置視為已驗證的上游能力。

上線前仍需站長提供計劃銷售的套餐與價格，並以明確的消費預算驗證“支付 → 上游扣款 → 資源變化 → 續費價格”流程。
