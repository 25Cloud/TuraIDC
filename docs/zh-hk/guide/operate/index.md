# 日常運營

系統上線之後的日常經營操作：上架商品、處理訂單與開通、對賬與退款、維護用戶與分銷關係、回覆工單、管理通知。

## 2. 每日建議複核

1. **未支付訂單**：看到期未付的訂單量與金額，判斷是否需要催付。
2. **開通失敗隊列**：支付成功但未開通的實例必須當天處理，用戶已付款。
3. **工單與超時**：有未回覆工單時先響應，避免觸發超時自動關閉。
4. **賬務一致性**：核對餘額變動與賬務流水是否對得上，有異常按[財務與賬單](finance.md)排查。
5. **通知失敗**：郵件或短信連續失敗通常意味着通道配置或配額出問題，見[通知與站內信](notifications.md)。

## 3. 不可逾越的操作邊界

- 支付記錄只改狀態，**不物理刪除**；任何資金相關的調整都要留下可追溯的記錄。
- 訂單、續費金額由服務端按規則重算，客戶端參數不能作為金額依據——手工改單時同樣遵守這個口徑。
- 已購用戶的實例不因商品下架而失效；下架隻影響新購。
- 涉及刪除表的操作一律不做，升級與遷移路徑依賴表結構穩定。
