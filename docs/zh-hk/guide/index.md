# 使用者文檔

面向部署並運營 TuraIDC 的站長與運營人員。這裡只講怎麼把站跑起來、怎麼配置業務、怎麼運營、出問題怎麼查；要看系統結構、接口契約或改代碼，請進[開發者文檔](../develop/index.md)。

## 1. 按階段進入

| 階段     | 你要完成的事                                       | 入口                            |
| -------- | -------------------------------------------------- | ------------------------------- |
| 部署安裝 | 選部署方式、準備環境、跑起後端與三端前端           | [部署安裝](deploy/index.md)     |
| 初始配置 | 站點與品牌、郵件與短信、支付渠道、上游供應商       | [初始配置](configure/index.md)  |
| 日常運營 | 商品上架、訂單開通、資金對賬、客服工單、通知       | [日常運營](operate/index.md)    |
| 維護升級 | 版本升級、備份恢復、日誌歸檔、前端站點 Nginx 規則  | [維護與升級](maintain/index.md) |
| 數據遷移 | 從智簡魔方財務系統或舊 IDC 系統遷移業務數據        | [數據遷移](migrate/index.md)    |
| 許可合規 | 確認 AGPL 免費路徑的強制義務，判斷是否需要商業授權 | [開源與商業許可](licensing.md)  |
| 故障排查 | 站點打不開、隊列不跑、郵件發不出等問題的定位與處理 | [故障排查](troubleshooting.md)  |

## 2. 上線最短路徑

1. 按[部署安裝](deploy/index.md)選擇一種方式完成部署，再照[部署與調度](deploy/scheduling.md)配好計劃任務、隊列與心跳——漏掉這一步，自動開通、自動續費與通知都不會執行。
2. 進[初始配置](configure/index.md)配好站點名稱與品牌、郵件與短信、支付渠道、上游供應商，然後才上架商品。
3. 用一筆真實的小額訂單走通「下單 → 支付 → 自動開通 → 通知」，確認閉環後再放量。
4. 把[備份與恢復](maintain/backup.md)設成定時任務，再開始對外銷售。

## 3. 環境自檢

部署完成後可隨時自檢 PHP 版本、必需擴展與禁用函數；升級 PHP 或改動 `php.ini` 後也應複核：

```bash
cd backend
php artisan app:doctor          # 必选项：版本、必需扩展、禁用函数
php artisan app:doctor --all    # 附带列出建议安装但不阻断的扩展
```
