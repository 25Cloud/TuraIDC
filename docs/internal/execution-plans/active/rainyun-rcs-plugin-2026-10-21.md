# 雨云 RCS 插件移植计划

## 背景

按[设计](../../designs/backend/rainyun-rcs-plugin.md)移植雨云 RCS 魔方插件。用户确认全部保留，并授权测试机器关机及重装；新购套餐资料稍后提供。

## 范围与验收

- [x] 插件扫描、供应商配置、套餐镜像与库存、开通续费和状态同步实现。
- [x] 开关机、重装、密码、VNC、监控、备份、快照、NAT、云盘、流量与 GPU 实现。
- [x] 付费操作走账单，权限、金额和重试行为有回归覆盖。
- [x] 完成安装说明、插件打包、文档校验及测试；明确真实测试与未验证项。
- [x] 用户可见的插件名称、操作提示、套餐配置、终端面板和附加资源账务描述去除“雨云”字样。
- [ ] 取得套餐、销售价格与消费预算后，验证真实新购、续费及付费扩展。

## 实施步骤

1. 核对原包、官方定义、平台调用方与测试环境。
2. 完成插件、受控面板和必要的通用能力接入。
3. 回归验证并交付安装包。

## 风险与回滚

停用插件前核对业务引用，不卸载业务绑定。付费请求超时不可直接重试，须保留待核对状态。测试密钥不进入仓库、文档、测试快照与打包产物。

## 进度

- [x] 原包、上游契约、官方 OpenAPI 核对；详情、镜像、套餐、监控、VNC 只读联调成功。
- [x] 插件与平台接入开发。核心只增加显式能力分支，无新增系统路由、调度、中间件或数据库表。
- [x] 新插件在授权空白实例上自动关机并提交 Debian 11 重装，随后确认恢复运行和目标镜像。
- [x] noVNC 与 xtermjs 官方页面浏览器直连成功，WebSocket 直达雨云节点。
- [x] 本任务后端 24 项回归、89 个断言通过；前端构建通过；5 项 e2e 分批通过。
- [x] 生成 `rainyun_rcs-1.0.0.zip`、完整源码补丁及统一交付包；包含许可与 SHA-256 校验清单。补丁在基线提交副本通过 `git apply --check`，应用后的 41 个文件与工作区一致。
- [ ] 真实收费链路联调。保留 active 状态，等待套餐、销售价格、明确消费预算及对应测试资源。
- [x] 按用户指定套餐 1344、镜像 535，以试用方式创建一台实例；零 IP 请求被拒绝，用户选择一个 `native` 原生 IP 后创建成功，实际余额减少 1 元。磁盘升降级不执行。

## 验证记录与剩余边界

- 后端命令：`php artisan test tests/Feature/RainyunRcsPluginTest.php tests/Feature/RainyunRcsPurchaseTest.php`。使用独立 SQLite 内存库，不修改开发库。缺少本地 `.env` 产生 24 条读取警告，退出码为 0。
- 前端命令：`pnpm run build`；`pnpm exec playwright test tests/e2e/rainyun-console-direct.spec.ts`。覆盖官方直连、其他插件内嵌行为、19.5 秒慢重装、终端入口失效、云盘字段切换和确认报价建单。
- 额外尝试原有 `ServiceVncTokenSecurityTest`：7 项断言通过，2 项因本机 `127.0.0.1:3306` 的 `idc_test` 不可达而失败。未把数据库环境错误视为功能通过，也未执行依赖该数据库的完整后端套件。
- 云盘退款、账单防重与续费价格更新经过内存库验证；实际支付网关、上游消费、完整 MySQL 事务及并发未联调。
- 云盘表单修复原生 `hidden` 属性被标签布局样式覆盖的问题，补充按操作切换字段与确认报价的浏览器用例。
- 备份、快照及 NAT 的接口映射和资源归属经过代码核对；备份还原与快照未执行真实数据操作。无额外生产依赖。1.0.0 实现已由用户提交，本轮试用适配修复尚未提交。
- 本轮真实开通通过 `provisionOrder`，使用隔离 SQLite 订单夹具持久化创建检查点；未接入图拉前台支付与实际业务数据库。`Try=true`、`OsID=535`、IPv4 线路 `native` 均已核对。
- 试用实例已进入 `running`，SSH 返回 Debian 服务标识；开启禁止上游写请求的检查后再次调用 `provisionOrder`，只复用创建检查点中的原实例，未重复购买。
- 本轮受影响的 `RainyunRcsPluginTest` 共 15 项、77 个断言通过；缺少本地 `.env` 的已知读取警告仍存在。未修改前端；文档校验通过。生成试用修复增量补丁供首次交付包使用，不覆盖原 1.0.0 包。
- 官方前端试用报价使用只读接口 `/product/rcs/price?scene=try&plan_id=1344`；当前报价为 1 元。创建零 IP 时明确返回 `70033`，原文为“本区域的产品至少需要一个IP”，插件已补充可操作的错误提示。
- 2026-10-22 文案修改验证：相关后端 27 项、128 个断言完成，退出码为 0，存在缺少本地 `.env` 的已知警告；6 项 e2e、控制台构建、PHP 与前端测试格式检查、文档校验通过。新增断言覆盖错误码映射、订单与退款描述、终端及套餐升级面板；插件代码中的“雨云”仅剩内部注释。未执行真实资源操作。
