# 备案号字段补全与页脚合规链接

## 背景

管理端「设置 → 备案与合规」只有 ICP 备案号、增值电信业务许可证号两个纯文本字段，缺公安备案号，且备案号在官网页脚只是纯文本，无法点击跳转到官方查询站。站长反馈：公安备案号没有地方填；ICP 备案号无法做成超链接。

目标：补齐公安备案号字段，并让三类备案号在页脚可点击。非目标：不改备案号文案、不改许可证号语义、不动备案业务办理流程。

## 范围与验收

- [ ] 管理端「备案与合规」新增公安备案号、ICP 备案号链接、公安备案号链接三个字段，四语语言包齐全。
- [ ] 后端 `basic` 设置组新增 `public_security_record`、`icp_record_url`、`public_security_record_url` 三个键，进入 `SiteConfigPayload`、`SiteConfigResource` 白名单、`SeoRenderService` 首帧注入与 `SettingsSeeder`。
- [ ] 官网页脚：ICP 备案号链接到工信部 `https://beian.miit.gov.cn/`；公安备案号链接到 `http://www.beian.gov.cn/portal/registerSystemInfo?recordcode=<号码中的数字>`；自定义链接非空时优先，且只允许 http/https 外链。
- [ ] 增值电信许可证号仍为纯文本，展示口径不变。
- [ ] 备案号或链接留空时不渲染空行；不引入客户端脚本；不写入任何私密信息。
- [ ] 后端字段清单测试、前端 store / 页脚四语语言包同步更新，`npm run build` 与 `pnpm run build` 通过。
- [ ] 部署到测试机实测：公安备案号有输入框、页脚三个备案号可点、链接指向正确、留空不显示空行。

## 实施步骤

1. 后端：`SiteConfigPayload` 读取三个新键；`SiteConfigResource` 白名单登记；`SeoRenderService` 首帧注入；`SettingsSeeder` 补默认空值；`V2SiteHomeApiTest` 字段清单与取值用例。
2. 管理端：`settings/index.vue` 合规区新增三个字段；四语语言包补 label / placeholder / hint。
3. 官网：`siteBranding` store 读取新键并计算「有效链接」（自定义优先、否则按备案号推导官方链接、严格 http/https）；`WebsiteLayout` 页脚用 `<a>` 渲染；四语语言包补公安备案号标签与链接无障碍文案。
4. 文档：`docs/guide/configure/site-settings.md` 与英/繁体镜像同步；`docs/catalog.json` 登记新计划。
5. 构建与部署：本地构建验证后部署测试机 `192.168.5.100`，实测管理端表单与官网页脚。

## 风险与回滚

- 后端字段白名单漏登记会导致「后台配了、接口不下发」，靠 `V2SiteHomeApiTest` 的字段清单测试兜底。
- 公安备案号的数字提取失败时不应生成坏链接：正则提取不到就不加 `recordcode` 参数，只链到平台首页。
- 自定义链接必须校验 http/https 协议，避免 `javascript:` 之类的注入；沿用官网 store 已有的 `normalizeExternalLink`。
- 文档站要求四语镜像同步，改完中文正文跑 OpenCC 脚本与英文契约校验，否则 `docs:check` 失败。
- 回滚：配置字段为新增且默认空值，不改旧数据；回滚代码即可，旧前台对新增键无感知。
