# 演示站（demo site）实施计划

## 决策日志

- **2026-11-09 一个 EO 项目、四个子目录**：分享一条域名即可；首页与演示同域把「看介绍 → 点进去」压到一次点击。备选是三个独立项目（各带各的 SPA fallback），代价是三个域名、三套部署。
- **2026-11-09 假数据放 axios adapter，不放调用点**：三端 `src/api/*.ts` 合计一两百个调用点，改调用点会把演示逻辑摊进业务代码；adapter 是正式扩展点且天然零网络。
- **2026-11-09 demo 构建改用 hash 路由**：EO 的 SPA fallback 只能整站一条 `/* → /index.html`，四个应用共域名时无法按前缀分别回退；hash 让 deep link 不需要服务端配置。仅 demo 构建生效。
- **2026-11-09 fixtures 用生成器而不是手写 JSON**：示例数据必须内部自洽（同一个客户在实例、账单、工单里要一致），生成器能共用一套基础数据；后续可替换为从真实测试实例录制。
- **2026-11-09 危险动作返回业务错误而不是假装成功**：演示站要让访客看到产品自己的错误提示链路，同时避免「点了删除好像真删了」的误解。
- **2026-11-09 假数据还要接一层 `window.fetch` 桥**：实测发现 AI 端点客户端（`shared/runtime/ai/client.ts`）只用原生 `fetch`、不走各端 axios 实例，只挂 adapter 会让它真打 `/api`（首轮冒烟里抓到的唯一 API 泄漏）。桥接只接管路径含 `/api/` 的请求，静态资源放行。
- **2026-11-09 fixture 落成每端一份 JSON 文件**（`demo/fixtures/{console,admin,user}.json`，由 `generate.mjs` 生成、`--check` 防漂移），而不是构建时动态拼：产物可复现、CI 能校验、diff 看得见。三端通过 `@demo-fixtures` 别名（vite + tsconfig 各一处）引用。
- **2026-11-09 TDesign 图标 webfont 的 CDN 列为已知例外**：`https://tdesign.gtimg.com/icon/0.4.5/fonts/index.js` 是 `tdesign-icons-vue-next` 里的硬编码常量，包内没有开关；冒烟用例把它单独放行，其余外网请求一律判红，后续在 demo 构建里挡掉或本地化。
