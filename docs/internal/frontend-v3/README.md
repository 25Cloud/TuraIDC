# 前端 v3 迁移台账与验收

`frontend-admin-v3` 与 `frontend-user-v3-www` 从旧前端迁移到 Vue 3 时的逐项台账与最终验收报告。台账记录每个模块的迁移状态与遗留项，验收报告记录交付时点的结论与已知问题。

| 前端                   | 迁移台账                                        | 最终验收报告                                               |
| ---------------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| `frontend-admin-v3`    | [管理端迁移台账](admin-v3-migration-ledger.md)  | [管理端最终验收报告](admin-v3-final-acceptance-report.md)  |
| `frontend-user-v3-www` | [官网迁移台账](user-v3-www-migration-ledger.md) | [官网最终验收报告](user-v3-www-final-acceptance-report.md) |

台账与验收报告反映迁移时点的状态，不是当前真源：现行前端约束以 [`docs/develop/frontend.md`](../../develop/frontend.md) 与 [`docs/develop/design.md`](../../develop/design.md) 为准。
