# 雨云 RCS 插件移植设计

依据用户提供的魔方财务 rainyunrcs 3.0.0 插件、雨云官方 OpenAPI 与授权测试实例，接入图拉上游插件体系。范围包含主机生命周期、控制台、备份、快照、NAT、云盘、流量、GPU 与付费扩展。

## 1. 目录与接入

- 雨云专有代码集中于 `backend/plugins/servers/rainyun_rcs/`，入口使用 `execute` 和平台能力接口。
- 复用供应商、商品与实例绑定；不新增系统级路由、插件鉴权或数据库表。
- 面板复用已有受控自定义区域，提交只接受服务端解析的实例与动作白名单。
- 核心通过 `ProvidesLocalConsoleActions`、`ProvidesConsolePurchaseFulfillment`、`ProvidesBrowserConsole`、`ProvidesReinstallTimeout` 显式启用扩展；雨云专有判断留在插件内。
- 插件动作同时检查实例绑定、插件 ID、供应商绑定和上游主机 ID。收费订单保存这些标识，换绑后拒绝旧订单履约。

## 2. 财务与重试

- 云盘、流量、GPU 时长、套餐升级及附加 IP 采用图拉账单及付款流程。报价十分钟有效，前端不能指定金额。
- 报价令牌同时写入账单快照，作为建单幂等标识；同一报价在付款完成后重提仍返回原账单，避免再次扣款或返还余额。
- 支付履约按通用能力接口分发，雨云协议留在插件内。非幂等写请求不自动重试；结果不明先回查或人工确认。
- 新购复用已绑定实例，保存上游结果后再做附属同步；续费只接受雨云支持的周期。
- 云盘负差额返还使用账户服务、余额流水和退款单据，在订单完成的同一事务中提交。同步更新服务金额及手动续费价格，不能计为管理员充值。
- 重装先校验镜像，再自动关机并轮询停机状态，总预算 55 秒；前端仅对声明时限的插件使用 90 秒请求超时。
- 官方 noVNC/xtermjs 完整页面在新窗口直连雨云，保留签名 URL，不通过图拉 relay 或 iframe 加载。

## 3. 原包差异与验证

- 移除向第三方站点发送 API 密钥与 SSH 密码的调用；终端使用雨云自身接口。
- 补齐原包只有页面调用、没有 PHP 实现的备份动作。
- 官方 OpenAPI 的 NAT 新增误标 GET，磁盘 action schema 也不完整，按源码与授权实测校对。
- 用户已授权空白测试实例的重装；新购、续费和付费扩展仍等待相应资料及消费授权。
