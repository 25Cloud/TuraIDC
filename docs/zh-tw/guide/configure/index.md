# 初始配置

部署完成到正式對外銷售之間的配置工作。按本文順序做完，再上架商品——支付渠道或上游供應商沒配好就放量，會出現使用者付了錢卻開不出機器的情況。

## 1. 配置順序

| 順序 | 配置項                             | 說明                                                   |
| ---- | ---------------------------------- | ------------------------------------------------------ |
| 1    | [站點與品牌設定](site-settings.md) | 站點名稱、瀏覽器標題、Logo、主題色等三端可見資訊       |
| 2    | [郵件與簡訊](mail-and-sms.md)      | 通知通道；不配則註冊驗證碼、開通通知、工單提醒都發不出 |
| 3    | [支付渠道接入](payment.md)         | 使用者付錢進來的通道，含回撥地址與金鑰紀律               |
| 4    | [上游供應商對接](upstream.md)      | 機器從哪裡開出來：憑據、庫存與定價同步、連通性自檢     |

## 2. 上線檢查清單

- 站點名稱與瀏覽器標題已改成本站品牌，前後臺與官網均已生效。
- 郵件能收到測試信，簡訊能收到測試驗證碼。
- 支付渠道的非同步回撥地址指向生產域名，且已在渠道側登記。
- 上游供應商連通性自檢通過，至少一個商品能查到真實庫存與價格。
- [部署與排程](../deploy/scheduling.md)裡的計劃任務、佇列與心跳已在執行。

## 3. 相關約束

- 金鑰、Token、私鑰只寫在伺服器環境變數或後臺加密配置裡，不寫進文件、截圖或工單。
- 簽名與令牌類金鑰讀到空值時必須拒絕服務，不允許降級成「空金鑰照常計算」。
- 修改品牌與站點資訊後，靜態資源可能被快取，需要按[前端站點 Nginx 規則](../maintain/nginx-rules.md)確認快取策略。
