# 雨雲 RCS 外掛

外掛目錄為 `backend/plugins/servers/rainyun_rcs/`，後臺能力域為 `upstream`，標識為 `rainyun_rcs`。本外掛對接雨雲 RCS，參考魔方財務 rainyunrcs 3.0.0 的業務功能重新實現。

## 1. 安裝前提

本版本需要配套的圖拉核心能力補丁和使用者控制台構建，不能只把外掛 ZIP 上傳到未升級的舊版圖拉。

交付包為 `TuraIDC-rainyun-rcs-1.0.0.zip`，內含 `rainyun_rcs-1.0.0.zip`、`TuraIDC-rainyun-rcs-integration.patch`、安裝說明、許可檔案及校驗清單。補丁基線是圖拉提交 `ec1afcb4b2920ae6e71fd5b92d5197341b10de19`；不同版本必須先檢查補丁，不要直接覆蓋整個應用。

首次交付包不包含隨後實測補齊的試用週期適配與缺少 IP 的錯誤提示。使用該包時還需應用 `TuraIDC-rainyun-rcs-trial-fix.patch`；此增量補丁基於已接入 1.0.0 的提交 `1661398`，同樣先執行 `git apply --check`。工作區已包含這些修改時不要重複應用。

配套能力包括：外掛本地控制台動作、外掛附加訂單履約、官方瀏覽器控制台直連、外掛重灌請求時限。平臺只有在當前例項繫結的外掛明確實現對應介面時才啟用相關分支；普通上游繼續使用原有流程。

1. 備份站點程式碼，確認當前版本與補丁基線相符。在倉庫根目錄先執行 `git apply --check TuraIDC-rainyun-rcs-integration.patch`，檢查通過後再應用。補丁包含完整外掛程式碼；不要重複覆蓋已有本地改動。
2. 按站點原有釋出流程部署後端，並在 `frontend-user-v4-console` 執行 `pnpm run build` 後部署構建產物。重新載入長駐佇列工作程序，清理舊應用快取。
3. 在管理端外掛管理中掃描、安裝並啟用“RCS”（標識 `rainyun_rcs`）。無需新增資料庫表或系統路由。
4. 新建或編輯供應商，選擇“RCS”，填寫 API 地址與 API 金鑰，再查詢餘額驗證連通性。金鑰只配置到供應商憑據，不放進商品、使用者端面板或文件。
5. 同步上游套餐、配置項和庫存，設定本站銷售價格，再關聯測試例項檢查控制台。

若圖拉已經包含這些配套能力，可單獨解壓外掛 ZIP，將 `rainyun_rcs` 目錄放入 `backend/plugins/servers/` 後掃描安裝。

## 2. 供應商與銷售價格

雨雲 API 地址為 `https://api.v2.rainyun.com`，請求頭由外掛設定 `x-api-key`。雨雲官方介面文件位於 <https://api.rainyun.com/>。

| 配置                       | 含義                                                                         |
| -------------------------- | ---------------------------------------------------------------------------- |
| API Key                    | 雨雲賬戶的 API 金鑰，預設時拒絕請求                                          |
| 固態、機械、系統機械盤單價 | 對應雲盤每 GB 每月的本站銷售價格                                             |
| 雲盤備份單價               | 開啟備份後，每 GB 每月的附加銷售價格                                         |
| 附加流量單價               | 每 GB 銷售價格                                                               |
| GPU 時長單價               | 每小時銷售價格                                                               |
| 套餐月銷售價格 JSON        | 套餐 ID 到月銷售價格的對映，例如 `{"1001":"30.00","1002":"60.00"}`           |
| IP 月銷售價格 JSON         | 線路標識到單個 IPv4 月銷售價格的對映，空標識表示預設線路，例如 `{"":"8.00"}` |

金額最多兩位小數。銷售價格缺失或無效時，對應購買會被拒絕，不能免費呼叫上游付費介面。套餐升級必須同時配置當前與目標套餐的銷售價格，並且目標必須出現在雨雲返回的可升級列表中。

匯入模板預設不附加付費 IP、額外系統盤容量，不啟用試用。若要開放開通時的附加配置或試用，由站長在商品配置中顯式設定選項、預設值與價格；模板的基礎套餐價格不能當成任意附加配置的總價。開通與續費支援月付、季付、半年付、年付。

試用開通支援訂單週期 `ontrial`（經平臺統一規範化也識別 `trial`、`on_trial`），或顯式配置 `try=true`；外掛向雨雲傳送試用開關，`duration` 仍使用介面允許的月數。此適配不改變圖拉商城的週期白名單，也不把試用加入續費週期。

部分割槽域必須附帶獨立 IP。套餐 1344 實測在數量為 0 時返回 `70033`，配置為 `with_eip_num=1`、`with_eip_flags=native` 後試用建立成功。該套餐還提供 `home_ip` 線路；IP 數量、線路與對應售價須在商品中顯式配置，不能沿用“不附加 IP”的預設選項。IP 線路標識與 IPv4/IPv6 地址型別是不同引數。

## 3. 控制台功能

| 功能                   | 行為                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 開關機、重啟、密碼重置 | 經圖拉鑑權後呼叫當前繫結例項的雨雲介面                                             |
| 重灌                   | 校驗映象後自動關機，等待確認停止，再提交重灌；無效映象不會關機，停機超時不提交重灌 |
| VNC                    | 獲取雨雲官方頁面連結，在新視窗訪問；不改寫簽名引數，不走圖拉 WebSocket 中轉        |
| 終端                   | 獲取 xtermjs 官方入口後，點選“開啟終端”直接訪問上游                                |
| 監控                   | CPU、記憶體、磁碟與網路時間序列                                                      |
| 備份與快照             | 建立、刪除、還原、自動計劃；備份支援取消任務                                       |
| NAT                    | NAT 例項顯示埠轉發列表、新增與刪除；資源 ID 必須屬於當前例項                     |
| 雲盤                   | 新建、擴容、調整備份、刪除資料盤；禁止縮容與刪除系統盤                             |
| 流量與 GPU             | 流量包、每日流量限額、限速、GPU 開關與時長購買                                     |
| 套餐與 IP              | 套餐升級、附加 IPv4 購買                                                           |

VNC 與終端頁面、WebSocket 均由瀏覽器直連雨雲。圖拉後端只請求入口連結及普通管理 API。若雨雲未返回 `VNCProxyURL`，外掛明確提示不可用；不提供舊式 `RequestURL/PVEAuth` 轉發方案。連結失效時重新獲取。

外掛展示名、操作提示、套餐配置、終端按鈕及新生成的附加資源賬單與退款描述使用中性文案，不包含“雨雲”。外掛標識、介面地址與繫結校驗仍沿用原值；已有商品配置和歷史賬務記錄不會被自動改寫。

雨雲重灌請求允許前端等待 90 秒，外掛內部前置操作總預算為 55 秒，並受平臺例項操作鎖保護。部署時 PHP 請求時限、反向代理讀取時限應允許該請求完成。重灌提交成功表示雨雲已接受任務，不表示安裝已完成；通過狀態重新整理確認恢復執行。

## 4. 附加資源賬單與重試

1. 使用者先獲取報價並確認。報價有效期十分鐘，繫結服務、供應商、外掛、上游例項和資源配置。
2. 建立圖拉昇級賬單，等待付款；同一確認報價重複提交時複用原賬單，付款完成後也不另建訂單。已有其他待支付升級賬單時，先支付或取消該賬單。
3. 付款後重新檢查例項繫結與資源狀態，再執行一次雨雲操作。
4. 雲盤、套餐和 IP 的月續費差額同步更新服務金額及相應續費週期配置。雲盤退款在上游成功後生成餘額流水與退款單據，不記為手工充值。

按原外掛口徑，以 31 天為一個月折算剩餘服務期；附加流量和 GPU 時長按購買數量計費。雲盤刪除及關閉備份的負差額按配置的銷售單價返還。遷入例項和調整供應商銷售價前，站長應核對該例項已有云盤費用是否計入圖拉續費金額，避免歷史定價與現配置不一致。

訂單快照狀態：`ready` 待執行，`submitted` 已發起，`applied` 上游已接受，`uncertain` 結果不明，`rejected` 上游拒絕。`submitted/uncertain/rejected` 不自動重發收費請求。換綁例項、變更上游資源或續期後，舊報價不能繼續執行。需核對上游真實結果及賬單，再按平臺現有人工賬務流程處理；不要清空執行狀態後盲目重試。

## 5. 驗證邊界

2026-10-21 已在授權空白例項上驗證詳情、套餐、映象、監控、餘額與兩種官方控制台入口，並通過新外掛執行“執行中 → 自動關機 → Debian 11 重灌”。瀏覽器驗證了連線直達雨雲 WebSocket。

同日通過外掛的真實開通入口驗證了套餐 1344、映象 535（Debian 12）、試用週期和一個 `native` IPv4：例項完成建立並進入執行中，試用標記、映象和 IP 線路正確，賬戶餘額減少 1 元；SSH 埠可達並返回 Debian 服務標識。再次呼叫開通入口只複用已儲存的例項 ID，沒有向上遊傳送寫請求。本次使用隔離的本地訂單夾具與真實上游介面，不包含圖拉前臺下單、支付閘道器或真實業務資料庫聯調。

正式付費新購、實際續費、套餐升級、售後附加 IP/雲盤/流量/GPU 購買未執行真實扣款；`home_ip` 只核對報價和引數，未建立第二臺機器驗證。使用者要求本輪不測磁碟升降級。備份還原及快照等資源操作以契約迴歸為主，生產啟用前應在對應測試資源驗證。原外掛沒有真實欠費封禁能力，本外掛也不把普通關機偽裝成封禁；不要把暫停狀態下的自動處置視為已驗證的上游能力。

上線前仍需站長提供計劃銷售的套餐與價格，並以明確的消費預算驗證“支付 → 上游扣款 → 資源變化 → 續費價格”流程。
