# 使用者文件

該文件面向部署並運營 TuraIDC 的站長與運營人員

若需檢視系統結構、介面或修改程式碼，請訪問[開發者文件](../develop/index.md)。

## 簡介

<p align="center">
    <img src="/branding/turaidc-logo.png" alt="TuraIDC Logo" width="400" />
</p>
TuraIDC 是一款面向 IDC / 雲服務商的業務與財務經營系統。該系統覆蓋商品管理、訂單計費、自動開通、發票、充值、分銷返佣、工單、通知等完整業務，提供管理後臺、官網門戶與使用者控制台三端前端，並通過可擴充套件外掛機制對接上游供應商與第三方服務。

## 核心能力

| 領域        | 能力                                                       |
| ----------- | ---------------------------------------------------------- |
| 🛒 商品     | 產品分組、配置項、庫存管理、自動開通、多計費週期           |
| 💰 財務     | 支付、餘額、充值、發票、退款、對賬、流水明細               |
| 👤 使用者管理 | 註冊登入、實名認證（可選）、會員等級、分銷與返佣、推廣提現 |
| 🎫 工單系統 | 部門分配、工單回覆、超時自動關閉、自動回覆、上下游傳遞     |
| 🔔 通知     | 站內信、郵件、簡訊（模板可配置）                           |
| ⚙️ 自動化   | 排程任務、心跳監控、定時對賬、日誌歸檔                     |
| 🔌 多外掛   | 供應商適配、支付閘道器、簡訊、驗證碼、郵件均以外掛形式接入   |

## 橫向對比

與部分友商的產品對比而言，我們的產品具有以下特性：

- **服務端計價**：金額、庫存、優惠券、續費全部服務端重算並加鎖，防止併發篡改。
- **完整審計日誌**：關鍵資金、訂單、後臺操作留痕，支援匯出與歸檔。
- **登入風控**：賬號 + IP 級軟鎖定、驗證碼目標維度限流、多入口統一校驗。
- **外掛化架構**：供應商、支付、簡訊、驗證碼、實名、郵件均以外掛接入，邊界清晰、可替換。
- **自動化兜底**：排程任務、心跳監控、定時對賬、失敗重試與自動掛起/釋放。
- **開源可審計**：AGPL-3.0-or-later 免費使用；可選商業授權（200 元/年）。

## 快速開始

1. 訪問 [部署安裝](deploy/index.md) 選擇一種方式完成部署。
2. 訪問 [部署與排程](deploy/scheduling.md) 配置服務端計劃任務、佇列與心跳。
3. 訪問 [初始配置](configure/index.md) 修改站點名稱與品牌、郵件與簡訊、支付渠道、上游供應商，然後再上架商品。
4. 建立測試賬號對「下單 → 支付 → 自動開通 → 通知」的流程進行測試，確認可用後再進行公開。
5. 把 [備份與恢復](maintain/backup.md) 設定為定時任務，再對外銷售。

## 環境自檢

部署完成後可隨時自檢 PHP 版本、擴充套件與停用函式；升級 PHP 或改動 `php.ini` 後也應進行復核：

```bash
cd backend
php artisan app:doctor          # 必选项：版本、扩展、禁用函数
php artisan app:doctor --all    # 附带列出建议安装但不阻断的扩展
```
